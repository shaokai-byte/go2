# go2
本文件夹基于unitree官网python服务接口unitree_sdk2_python文件夹中high_level和front_camera文件中的程序，继续拓展了对机器狗动作控制和相机识别的程序。并增加了yolo11训练目标物体检测模型的全流程项目。

### 第一次学习且接触机器狗的先完成go2基础开发指南.pdf中内容，再学习此文档！！！

## 前提
已完成官网（https://support.unitree.com/home/zh/developer/Python）python服务接口环境部署 ，并安装unitree_sdk2_python

已成功运行unitree_sdk2_python/example/go2/high_level文件夹中的程序

已成功运行unitree_sdk2_python/example/go2/front_camera文件夹中的程序

## camera
机器狗相机不同的模型识别和控制程序
## sport
机器狗动作不同的动作控制程序
## yolo11
yolo11训练目标物体检测模型的全流程核心文件夹
