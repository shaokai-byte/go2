# YOLO11 目标检测项目 README

## 项目概述
本项目是基于YOLO11的目标检测系统，主要用于检测足球场景中的球和门柱等目标。
支持训练自定义模型、预测和目标跟踪功能。

## 目录结构
```
train_yolo11/
├── yolo_dataset/                    # YOLO格式数据集
│   ├── train/                       # 训练集
```

## 数据集结构说明

### 1. 数据集格式
本项目使用YOLO格式数据集，包含以下组件：

**图像文件**: 支持.jpg, .jpeg, .png格式
**标签文件**: .txt格式，每行包含一个目标的标注信息
- 格式：`class_id x_center y_center width height`
- 坐标均为相对于图像尺寸的归一化值（0-1）

### 2. 类别定义
当前模型支持5个类别：
- 0: Ball (球)
- 1: Post (门柱)
- 2: L (L形标记)
- 3: T (T形标记)
- 4: X (X形标记)

## 如何训练自己的模型

### 1. 环境准备
方式1：conda env create -f yolo11.yaml
方式2：
确保安装了必要的依赖：
```bash
pip install ultralytics
pip install torch torchvision  # 根据你的CUDA版本选择合适版本
```

### 2. 数据准备
- 准备你的数据集，确保符合上述数据集结构

### 3. 训练参数配置
在train.py中可以调整以下关键参数：

**模型选择**:
- yolo11n.pt: 轻量级模型，速度快
- yolo11s.pt: 小型模型，平衡速度和精度
- yolo11m.pt: 中型模型
- yolo11l.pt: 大型模型
- yolo11x.pt: 超大型模型，精度最高

**训练参数**:

#### 参数作用说明：
- epochs: 训练轮数，控制模型训练的总轮次
- batch: 批次大小，每次训练处理的图像数量
- imgsz: 输入图像尺寸，模型输入图像的像素大小
- device: 计算设备选择（'0'表示第一块GPU，'cpu'表示使用CPU）
- lr0: 初始学习率，控制模型参数更新的步长
- optimizer: 优化器类型（auto/SGD/Adam/AdamW等）
- workers: 数据加载线程数，影响数据读取速度
- patience: 早停耐心值，验证指标不改善时等待的轮数
- amp: 混合精度训练，可加速训练并节省显存

#### 可参考参数设置：
- epochs: 350
- batch: 32
- imgsz: 960
- device: '0'
- lr0: 0.01
- optimizer: 'auto'
- workers: 8
- patience: 100
- amp: True

### 4. 训练过程图表说明

训练完成后，在`runs/train/football_detection/`目录下会生成多种图表，用于分析训练效果：

#### 常见图表及其作用：

**F1_curve**:
- F1分数曲线，展示不同置信度阈值下的F1分数变化
- F1分数是精确率和召回率的调和平均数，平衡两者的重要性
- 帮助选择最佳的置信度阈值，使F1分数达到最大值

**P_curve**:
- 精确率曲线，展示不同置信度阈值下的精确率变化
- 精确率 = 真阳性 / (真阳性 + 假阳性)
- 曲线越高表示在相应置信度下精确率越好

**PR_curve**:
- 精确率-召回率曲线，展示精确率和召回率之间的权衡关系
- 曲线下面积(AUC)越大表示模型性能越好

**R_curve**:
- 召回率曲线，展示不同置信度阈值下的召回率变化  
- 召回率 = 真阳性 / (真阳性 + 假阴性)
- 曲线越高表示在相应置信度下召回率越好

**confusion_matrix**:
- 混淆矩阵，展示各类别的预测结果与真实标签的对应关系
- 对角线表示正确分类的数量，非对角线表示错误分类
- 帮助识别哪些类别容易被误分类，以及具体的混淆情况

**confusion_matrix_norm**:
- 归一化混淆矩阵，将混淆矩阵中的数值转换为百分比形式
- 更直观地展示各类别的分类准确率和错误率
- 便于不同类别之间的性能比较，不受样本数量不平衡影响

### 4. 开始训练
```bash
python train.py
```

训练过程中会自动：
- 创建并更新数据集配置文件
- 加载预训练模型
- 进行训练和验证
- 保存最佳模型权重到runs/train/football_detection/weights/

### 5. 训练监控
训练结果保存在runs/train/football_detection/目录下：
- weights/: 模型权重文件
- 训练过程图表和日志文件

- 验证结果可视化

## 如何运行预测任务

### 1. 图像/视频预测

**预测参数**:

#### 参数作用说明：
- source: 输入源路径（图像/视频/摄像头/流地址）
- save: 是否保存带标注的预测结果
- save_txt: 是否保存YOLO格式的检测框坐标文件
- save_conf: 是否在txt文件中保存置信度信息
- conf: 置信度阈值，过滤低置信度的检测结果
- iou: NMS IoU阈值，控制重叠框的合并程度
- project: 结果保存的根目录路径
- name: 实验名称，创建子目录用于保存结果


**脚本功能**:
- 自动加载最佳训练模型
- 对predict_data/vedio目录中的文件进行预测,可以自己录制数据进行测试
- 保存带标注的结果图像
- 生成YOLO格式的检测结果文件

**输出结果**:
- 带标注框的图像/视频文件
- .txt格式的检测框坐标文件
- 置信度信息
