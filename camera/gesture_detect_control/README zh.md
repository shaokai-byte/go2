# gesture_detect_control
本文件夹核心是通过调用mediapipe库进行手势识别 ，识别到再调用机器狗基础动作。
已完成手势识别后调取动作任务，后续可继续尝试人脸识别

## 环境
unitree_sdk2_python基础环境
mediapipe库安装
pip install mediapipe

## 程序复件
备份程序
## gesture_detect_control.py
原始程序
##2gesture_control.py
优化程序

##使用方法
终端在该文件夹目录文件下python3运行即可
# python3 2gesture_control.py
# python3 gesture_detect_control.py

##注意
程序中可更改识别的时长和调取的动作
