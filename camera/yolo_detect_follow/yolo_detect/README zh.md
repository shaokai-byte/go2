# yolo_detect
目标物体检测两个程序
已完成模型文件中的模型识别，后续可继续调用识别其他目标检测物体

## 环境
unitree_sdk2_python基础环境
opencv库安装（大部分自有）

## many_bestpt_yolo_detect.py
三个模型同时运行识别
## only_bestpt_yolo_detect.py
一个模型运行识别


##使用方法
终端在该文件夹目录文件下python3运行即可
# python3 many_bestpt_yolo_detect.py
# python3 only_bestpt_yolo_detect.py

##注意
程序中调用模型的路径是绝对路径，运行时要改为自己电脑中模型所在的绝对路径
