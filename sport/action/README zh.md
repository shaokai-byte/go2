# action
本文件夹中的程序是基于 go2_sport_client.py程序中对动作函数的调用和更改
完成了对机器狗动作的不同控制方法

## 环境 
unitree_sdk2_python基础环境

## 程序复件
备份程序
## go2_add_sport_client.py
在原go2_sport_client.py程序中新增了其它动作调用
## continuous_action.py
将动作进行汇总，可一次性执行多种动作

##使用方法
终端在该文件夹目录文件下python3运行即可
# python3 go2_add_sport_client.py
# python3 continuous_action.py
