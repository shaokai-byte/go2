# walk
本文件夹中的程序是基于 go2_sport_client.py程序中id=3 move函数的调用和更改
完成了对机器狗行走的不同控制方法

## 环境 
unitree_sdk2_python基础环境


## 程序复件
备份程序
## walk1.py
采用原有move(x,y,z)移动序列方法，每做一次动作都需增加一次move
## walk2.py
将move(x,y,z)移动序列格式改为数组的形式
## walk3.py
通过移动速度判断移动距离，直接填写移动距离即可
## walk4.py
将行走分步执行，每一步做一段距离行走

##使用方法
终端在该文件夹目录文件下python3运行即可
# python3 walk1.py
# python3 walk2.py
....
